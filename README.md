# FocusFlow ⏱️

A simple Pomodoro timer with a built-in task list, built **100% by voice using** [**Wispr Flow**](https://ref.wisprflow.ai/hhg).

🔗 **Live demo:** https://bhaveshkundwani.github.io/focusflow-pomodoro/
🎥 **Demo video:** https://youtu.be/eAX3pN3KlNo

## Features

* 25-minute focus sessions with an automatic 5-minute break
* Start, Pause and Reset controls
* Circular progress ring that fills as time passes
* Beep sound when a session ends
* Task list: add, tick as done, and delete tasks
* Daily stats: sessions completed and total focus minutes (reset every new day)
* Tasks, stats and theme are saved in the browser (localStorage)
* Dark and light theme toggle
* Press **Space** to start or pause
* Responsive layout that works on mobile

## Tech Stack

HTML, CSS and vanilla JavaScript. No frameworks or dependencies.

## How to Run

1. Clone the repo:

```bash
   git clone https://github.com/bhaveshkundwani/focusflow-pomodoro.git
   ```

2. Open `index.html` in any browser.

No install or build step is needed.

## Project Structure

```
focusflow-pomodoro/
├── index.html   # page structure
├── style.css    # styling, themes and responsive layout
└── script.js    # timer, tasks, stats, theme and shortcuts
```

## Built With Voice

This project was built entirely with voice dictation using Wispr Flow, with an AI coding tool turning the spoken prompts into code. The full process is shown in the demo video above.
